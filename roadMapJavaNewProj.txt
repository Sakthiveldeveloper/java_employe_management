# 🚀 Spring Boot Learning Roadmap (Employee Management System)

> Author: Sakthivel A
> Mentor: Nova 🤖
> Goal: Learn Spring Boot from scratch by building a production-style Employee Management System.

---

# 📖 Purpose

This project is NOT about copying code.

The goal is to understand:

- Why each layer exists.
- How Spring Boot works internally.
- How to debug issues.
- How to think like a backend engineer.

Every phase should be completed manually.

Never copy the entire code.

Understand → Build → Debug → Test → Improve.

# 📌 PHASE 8 – Debugging Guide

404

Meaning

```
URL Not Found
```

Check

- URL
- Controller
- Package

---

405

Meaning

```
Method Not Allowed
```

Check

- GET
- POST
- PUT
- DELETE Mapping

---

500

Meaning

```
Application Error
```

Read

```
Stack Trace

↓

Root Cause

↓

Fix
```

Never read only the first line.

Read from the bottom.

---

Bean Not Found

Check

```
@Service

@Repository

@Component

Package Scan
```

---

Repository Not Found

Check

```
JpaRepository

↓

Package

↓

@SpringBootApplication
```

---

Hibernate Error

Check

```
Entity

↓

@Column

↓

Database Schema

↓

DDL
```

---

Database Error

Check

```
Database Running

↓

Username

↓

Password

↓

application.yml
```

---

Whitelabel Error

Check

```
Application Running?

↓

Controller Exists?

↓

Request Mapping?
```
